# Event Mockup AI Generator 🎨️🤖

A browser-based canvas editor for generating event backdrop mockups with integrated AI-powered product suggestions.

## 🚀 Overview

**Event Mockup AI Generator** streamlines event design and sourcing by combining a drag-and-drop canvas editor with AI-driven Amazon product recommendations. Users can design high-resolution event backdrops, banners, and decor mockups with ease and receive AI-suggested product links based on text elements on the canvas.

## ✨ Features

✅ Browser-based canvas editor for mockup creation  
✅ Drag-and-drop PNG asset support for custom layouts  
✅ AI-generated Amazon product links based on canvas text prompts  
✅ High-resolution export for professional event mockups  
✅ Reduces manual design and sourcing time for event planners  

## 🛠 Tech Stack

- **Frontend:** React  
- **Canvas Rendering:** HTML5 Canvas API  
- **AI Integration:** Prompt-based search inference for product suggestions  
- **Export:** High-resolution image export functionality  

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/kiran12ds/event-mockup.git
cd event-mockup
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The app will be available at `http://localhost:3000`.

## 🖥 Usage

1. Open the application in your browser.
2. Use the drag-and-drop interface to position PNG assets on the canvas.
3. Enter text prompts on the canvas; AI will suggest relevant Amazon products (e.g., stands, banners, decor).
4. Export your mockup in high-resolution for event planning or client presentations.
